# 🚗 NaldexCar — Site Institucional

Site institucional desenvolvido para a **NaldexCar**, uma oficina de serviços automotivos localizada em Timon – MA.

O projeto tem como objetivo fortalecer a presença digital da oficina, apresentar seus serviços, facilitar o contato com clientes e proporcionar uma experiência de navegação moderna, intuitiva e responsiva.

## 🌐 Demonstração

🔗 **Acesse o site:** [NaldexCar](https://naldexcar.netlify.app)

## 📌 Sobre o projeto

O site foi desenvolvido com foco na divulgação dos serviços da oficina e na facilidade de comunicação entre a empresa e seus clientes.

A interface apresenta uma identidade visual automotiva, com navegação simples, organização das informações e integração com ferramentas externas.

## ✨ Funcionalidades

- **Página inicial:** apresentação da empresa e chamadas para contato.
- **Serviços automotivos:** apresentação dos principais serviços oferecidos pela oficina.
- **Galeria de imagens:** exposição dos trabalhos realizados, organizada por categorias.
- **Sobre a empresa:** informações sobre a história, missão e compromisso da NaldexCar.
- **Integração com WhatsApp:** acesso direto para agendamento de serviços.
- **Localização:** endereço e mapa integrado com Google Maps.
- **Redes sociais:** integração com o Instagram da empresa.
- **Design responsivo:** adaptação para computadores, tablets e smartphones.
- **Menu interativo:** navegação adaptada para dispositivos móveis.

## ⚙️ Como executar o projeto

1. Clone este repositório:

```bash
git clone https://github.com/AntenorSantos/naldexcarsite.git
```

2. Entre na pasta do projeto:

```bash
cd naldexcarsite
```

3. Abra o arquivo `index.html` no navegador.

Também é possível executar utilizando a extensão **Live Server** no Visual Studio Code.

## 🔧 Personalização

As principais informações da empresa podem ser alteradas no arquivo `script.js`, incluindo:

- Número de telefone e WhatsApp.
- Mensagem automática de atendimento.
- Endereço da oficina.
- Link do Google Maps.
- Perfil do Instagram.
- Categorias e imagens da galeria.

## 📱 Responsividade

O projeto foi desenvolvido para oferecer uma experiência de navegação em diferentes tamanhos de tela, permitindo que os clientes acessem as informações da oficina tanto pelo computador quanto pelo celular.
